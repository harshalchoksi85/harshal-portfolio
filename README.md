# Harshal Choksi — GitHub Pages Portfolio

A responsive, static personal portfolio focused on engineering leadership, platforms, architecture, product delivery and organizational effectiveness. Built with HTML, CSS and vanilla JavaScript so it can be hosted directly on GitHub Pages without a build step.

## What's included

- `index.html` — portfolio homepage and section navigation
- `styles.css` — responsive visual system and layouts
- `script.js` — mobile navigation and current-year footer
- `assets/Harshal-Choksi-Executive-Resume.pdf` — PDF CV for visitors
- `assets/Harshal-Choksi-Executive-Resume.docx` — editable Word CV

## Before publishing

1. Replace `YOUR-GITHUB-USERNAME` in the GitHub profile link in `index.html` with your actual GitHub username.
2. Replace the generic LinkedIn link with your actual LinkedIn profile URL.
3. Review the CV and all public claims before publishing. Remove anything confidential or not approved for public sharing.
4. Add links only to real projects or repositories that you are comfortable making public.

## Publish with GitHub Pages

### Option A — Recommended: user site

1. Sign in to GitHub and create a **public repository named exactly** `YOUR-GITHUB-USERNAME.github.io`.
2. Upload all files and folders in this package to the repository root (`index.html` must be at the root).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After deployment, the site should be available at `https://YOUR-GITHUB-USERNAME.github.io/`.

### Option B — Project site

1. Create a repository, for example `executive-portfolio`.
2. Upload the contents of this package to its root.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. The site should be available at `https://YOUR-GITHUB-USERNAME.github.io/executive-portfolio/`.

Relative links are used for site assets so the site can work as a project site as well.

## Updating the portfolio

- Edit `index.html` to update the profile, professional themes and links.
- Edit `styles.css` to adjust colors, spacing and typography.
- Keep public project descriptions accurate and avoid publishing proprietary source code, customer information, internal metrics or confidential company plans.
